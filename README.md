# Plateforme éducative (démo)

Petit site web où les professeurs publient des cours et des sujets et gèrent leur planning, les étudiants consultent les documents et les plannings, et l'administrateur gère les matières et les professeurs.

Version de démonstration en HTML, CSS et JavaScript : les données restent dans le navigateur (localStorage), sans serveur ni mot de passe.
